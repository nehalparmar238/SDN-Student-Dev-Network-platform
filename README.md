# SDN – Student Dev Network

SDN is a full-stack student technology community web platform where students can create profiles listing their technical skills, publish technology projects, apply to join peer projects, and register for workshops, events, and hackathons. Administrators have full moderation capabilities over users, projects, events, categories, and join applications.

## Technology Stack
* **Backend:** PHP 8.0+ (plain PHP with MVC architecture)
* **Database:** MySQL (accessed securely via PDO with prepared statements)
* **Frontend:** HTML5, CSS3, and Vanilla JavaScript (fully offline-compatible, no external CDNs or frameworks)
* **Server Environment:** XAMPP (Apache + MySQL) on Windows
